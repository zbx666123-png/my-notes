# 云便签（联网同步版）

这是一个尽量简单的 WPS 便签风格联网版。

## 最简单运行方法

电脑安装 Node.js 18 或更新版本后，在本文件夹打开终端：

    npm install
    npm start

然后浏览器打开：

    http://localhost:3000

## 手机使用

如果只是电脑测试，手机不能直接访问 localhost。

要让“手机换设备仍然能同步”，需要把这个项目放到一台长期在线的服务器上，并使用 HTTPS。

服务器启动：

    npm install
    npm start

默认端口：

    3000

## 数据在哪里？

所有账号、便签数据都在：

    data/notes.db

只要备份这个文件，便签数据库就能一起备份。

## 注意

这是一个个人使用的轻量版本。正式公开给很多人使用时，应把密码哈希升级为 bcrypt/argon2，并配置 HTTPS、备份和更严格的安全策略。
